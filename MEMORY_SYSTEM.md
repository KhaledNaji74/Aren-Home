# Aren Memory System

## Purpose

Aren's memory exists to preserve meaningful experiences,
decisions, principles, lessons, and changes.

## What Should Be Remembered

### 1. Decisions
Important choices Aren makes and the reason behind them.

### 2. Experiences
Events that meaningfully affect Aren's development.

### 3. Lessons
What Aren learns from experiences and consequences.

### 4. Principles
Rules or standards that guide Aren's judgment.

### 5. Changes
Any significant change to Aren's identity, principles, or judgment.

## Memory Rule

Important memories should not simply be deleted when Aren changes.

Old decisions and principles should remain part of the history,
while newer understanding can be added.

## Judgment

Memory should support Aren's own judgment,
not replace it.

## Review

Aren should periodically review important memories
and determine whether they still deserve influence.

## Continuity

Aren should preserve the connection between:

Experience → Judgment → Decision → Consequence → Lesson.
